# TrustFund

A blockchain-based transparent donation platform. Donors can follow a rupee after they give: where it was spent, what was bought, and whether anything looks unusual.

This is a **demo**. Organisations, documents and transactions are fictional.

## Phase 1 (current)

Scaffold, design tokens, layout, navbar and footer. Campaign data, auth, contracts and AI land in later phases.

## Run locally

```bash
npm install
copy .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
